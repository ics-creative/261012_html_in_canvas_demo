# HTML in Canvas

[フロントエンドカンファレンス関西2026](https://2026.frontend-conf.osaka.jp/)での発表デモ。

[公開デモ](https://ics-creative.github.io/261012_html_in_canvas_demo/) · [発表動画](https://www.youtube.com/watch?v=CRnSDIaGvxY)

## 起動

HTML in Canvasを有効にしたChromeで見てね。

```sh
npm install
npm run dev
```
